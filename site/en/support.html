What is Unterwegs?

Unterwegs - Travel Log is an Android and iPhone app for reading collections of your AdventureLog server while travelling: day plan, lodging, trains, booking numbers, PDFs and maps, even without internet. With a connection you can also edit locations, lodging, transportation, notes and photos.

The app is unofficial and not part of the AdventureLog project.

You need your own AdventureLog server

The app contains no travel data and has no account service of its own. You need an AdventureLog server (self-hosted, or run for you by someone else) and an account there. To try it out, the sign-in screen offers the public test server; do not upload personal data there.

HTTPS is required

The app sends your API key with every request, so it connects only over https://. The easiest way is to give the server an address with a valid certificate, for example:

  • Tailscale: “tailscale serve” makes the server reachable at https://<name>.ts.net for all devices in your tailnet.
  • Your own or a free domain with a reverse proxy such as Caddy, which gets a Let's Encrypt certificate automatically.

Without a domain: create your own certificate for the server's address (for example with Caddy's “tls internal” or mkcert; it must be valid for exactly the address you enter in Unterwegs) and install the root certificate (CA) on the phone. iPhone: open the .crt file, install the profile in Settings, then turn on full trust under General → About → Certificate Trust Settings. Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Only install certificates you created yourself; whoever controls a root certificate can read encrypted connections. The app shows this help on the sign-in screen too (“No HTTPS? Here's how”).

Signing in

  • Scan QR code: on the AdventureLog website, Settings → Mobile App shows a QR code. The app shows the server from it and signs in only after you confirm.
  • Sign in in the browser: the app opens your server's sign-in page. Your server's password and single sign-on (SSO) work there; afterwards the app takes over an API key.
  • With an API key: website → Settings → API keys. Only needed if nothing else works.

Using it offline

The app stores your collections locally and opens them without internet. Before a trip, download the collection for offline use (PDFs, photos) and, if needed, map areas. Changes need a connection.
