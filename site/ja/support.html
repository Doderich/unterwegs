Unterwegs とは

Unterwegs - Travel Log は、AdventureLog サーバーのコレクションを旅先で読むための Android / iPhone アプリです。日程、宿泊、列車、予約番号、PDF、地図を、インターネットがなくても確認できます。接続中は、場所、宿泊、交通、メモ、写真の編集もできます。

本アプリは非公式で、AdventureLog プロジェクトの一部ではありません。

ご自身の AdventureLog サーバーが必要です

アプリには旅行データも独自のアカウントサービスもありません。AdventureLog サーバー(自前運用、または他の方が運用しているもの)とそのアカウントが必要です。お試し用に、サインイン画面から公開テストサーバーを選べます。個人データはアップロードしないでください。

HTTPS が必須です

アプリはリクエストのたびに API キーを送信するため、https:// でのみ接続します。最も簡単なのは、有効な証明書のあるアドレスをサーバーに付けることです。例:

  • Tailscale:「tailscale serve」で、サーバーを tailnet 内のすべての端末から https://<name>.ts.net で利用できます。
  • ご自身のドメインまたは無料ドメインと、Let's Encrypt の証明書を自動取得する Caddy などのリバースプロキシ。

ドメインがない場合:サーバーのアドレス用に自分で証明書を作成し(例:Caddy の「tls internal」または mkcert。Unterwegs に入力するアドレスと完全に一致している必要があります)、ルート証明書(CA)をスマートフォンにインストールします。iPhone:.crt ファイルを開き、設定でプロファイルをインストールし、「一般」→「情報」→「証明書信頼設定」でフルアクセスを有効にします。Android:設定 → セキュリティ → 暗号化と認証情報 → 証明書のインストール → CA 証明書。ご自身で作成した証明書のみインストールしてください。ルート証明書を管理できる人は、暗号化された通信を読み取れます。アプリのサインイン画面にも同じヘルプがあります(「HTTPS がない場合」)。

サインイン

  • QR コードをスキャン:AdventureLog のウェブサイトの「設定」→「Mobile App」に QR コードが表示されます。アプリはそこからサーバーを表示し、確認後にサインインします。
  • ブラウザでサインイン:アプリがサーバーのサインインページを開きます。サーバーのパスワードやシングルサインオン(SSO)がそこで使え、その後アプリが API キーを受け取ります。
  • API キーでサインイン:ウェブサイト →「設定」→「API キー」。他の方法が使えない場合のみ必要です。

オフラインでの利用

アプリはコレクションを端末に保存し、インターネットなしで開けます。旅行の前に、コレクションをオフライン用にダウンロード(PDF、写真)し、必要なら地図エリアもダウンロードしてください。変更には接続が必要です。
