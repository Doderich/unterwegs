# Maps with MapLibre and OpenFreeMap

Maps use MapLibre with OpenFreeMap's OpenStreetMap vector tiles on both platforms: no API key, no Google dependency, the same look on Android and iOS, and MapLibre caches viewed tiles for offline use. Apple and Google maps would differ per platform and need keys; the official OSM tile servers forbid app use. Since 1.3.0, use MapLibre's native offline packs for explicit downloads (including style, glyphs and sprites), rather than introducing a PMTiles server. Collection overviews reduce detail to fit OpenFreeMap's [download policy](https://openfreemap.org/quick_start/); individual locations/lodging can be saved at street detail. The planner counts Liberty's vector and Natural Earth raster tiles targeting 128 tiles to leave room for heavy city tiles below the 3,000-tile allowance, and downloads pause at 45 MiB to leave headroom below the 50 MB allowance; a config plugin caps native networking at four requests and sets the app User-Agent. Packs use the light style offline, expose progress/size and pause/resume/delete, and can be evicted by the OS under storage pressure. Self-hosted PMTiles remain an option for larger areas.
