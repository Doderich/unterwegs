# Distribution without app stores

Superseded by [0014](0014-store-distribution.md): the app moves to Google Play and the App Store. Until the store apps are live, this channel stays in use.

Android builds are published as GitHub releases of the private app repository, which family phones follow with Obtainium and a read-only token (planned before as a self-hosted F-Droid repository with Droid-ify; releases need no server of their own); iOS goes through TestFlight on a paid Apple Developer team (sideloaded with SideStore before there was one). JavaScript-only changes ship as over-the-air updates from a self-hosted update server (`expo-updates`, see `docs/RELEASING.md`), public for the update paths only. The repository stays private: a release APK carries the owner's server and update URLs. Android costs nothing and needs no review; iOS costs the yearly Apple Developer membership, and internal TestFlight testers need no review. Fixes can reach phones during a trip. The cost: the Android signing key must never be lost, TestFlight builds expire after 90 days and need a new upload before then, and an update only reaches builds with the same app `version`, so native changes need a new build installed on every phone.
